📊 Dashboard Porsche com IA

Projeto desenvolvido no desafio Criando uma Dashboard da Porsche com Agentes de IA.  
Transformei uma planilha de 100 vendas sanitizadas em uma dashboard interativa em HTML, publicada via GitHub Pages.

---

🚀 Perguntas de Negócio

1. Modelos mais vendidos  
2. Receita total por cidade  
3. Métodos de pagamento mais utilizados

---

🛠️ Tratamento da Base

- Uso apenas das colunas sanitizadas  
- Conversão de preço e ano para números  
- Padronização de métodos de pagamento  
- Remoção de registros com datas inválidas  

---

✍️ Prompt

```
Crie uma dashboard em HTML com filtros de modelo, cidade, ano e método de pagamento. 
Inclua gráficos para: vendas por modelo, receita por cidade e distribuição por método de pagamento. 
Adicione indicadores de topo com total de vendas e receita. 
Use paleta inspirada na identidade visual da Porsche.
```
